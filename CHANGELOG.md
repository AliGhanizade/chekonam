# Changelog

## [2.1.0] - 2026-09-13

- Added persistent strike-through choices based on stable option IDs.
- Added per-category strike limits based on list size.
- Added bilingual Persian and English catalogs with matching IDs.
- Varied category sizes and expanded the food catalog.
- Added the custom planet favicon.
- Added the selected option title to the revealed card.

## [2.0.0] - 2026-09-13

- Added the hidden card, automatic pick, and scratch-card modes.
- Added five visual themes, color scheme switching, custom colors, and 2D/3D depth.
- Added custom boards and browser-local statistics.
- Removed audio playback to keep the experience quiet and lightweight.

## [1.0.0] - 2026-09-13

- First static release for GitHub Pages.
- Added category-based decision lists, local preferences, and responsive layout.
